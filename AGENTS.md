# AGENTS.md

## Sobre o projeto

Implementação do [tabnews.com.br](https://www.tabnews.com.br) para o [curso.dev](https://curso.dev), desenvolvida com o auxílio de agentes de IA.

## Stack

- **Next.js 16.2.12** (versão fixada exatamente no `package.json`) com **App Router**
- **React 19**
- JavaScript (sem TypeScript)
- CSS global puro (sem frameworks de estilo)

## Comandos

```bash
npm install      # Instala dependências
npm run dev      # Servidor de desenvolvimento em http://localhost:3000
npm run build    # Build de produção
npm run start    # Serve o build de produção
```

## Convenções

- Manter o código mínimo e seguir as convenções modernas do Next.js (App Router, Server Components por padrão).
- Textos e idioma da interface em português (pt-BR).
